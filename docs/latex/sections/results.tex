\noindent\textbf{Working conclusion.}
On this M4 Hourly split, ungated correction does not win overall, but the
$\Delta$ is heterogeneous: v1 is near a coin-flip with mild trend structure;
v2's damage is concentrated (smooth / highly seasonal series), while one
high-volatility slice is net-positive. Next method step: a gate / abstain rule.
