\noindent\textbf{Working conclusion.}
Ungated correction fails, but abstaining rescues it, and this survives honest
rule selection: with the rule picked on val only, v2 reaches test MASE $1.055$
vs base $1.070$ ($p=0.027$) while v1 stays inside noise ($p=0.075$). Next method
step: a learned $\gamma$ gate (or hard gate inside the corrector), then a cleaner
non-leaked suite before any strong claim.
